# Oil Painting Website

This website is a personal portfolio for artist Siyu Zhong, showcasing oil paintings and conceptual artwork in a refined, immersive layout.

## Features

- Horizontal 3D gallery with drag and scroll navigation
- Artwork detail modal with title, medium, size, and year
- Archive page for browsing featured paintings and a gallery grid
- Smooth scroll reveal and organic cursor interactions
- Responsive layout adapted for both desktop and smaller screens

## Purpose

The site is designed to present a cohesive visual experience that highlights the emotional and atmospheric qualities of the paintings while keeping the interface clean and elegant.

## Files

- `index.html` — Main portfolio landing page with the horizontal gallery
- `gallery.html` — Archive page with featured work and a grid layout
- `style.css` — Styling for both pages and gallery effects
- `script.js` — Interactive gallery behavior, modal navigation, and animations
- `fluid-cursor.js` — Organic cursor effect overlay

## Notes

Update the artwork `data-title`, `data-medium`, `data-size`, and `data-year` attributes in the HTML files to keep the details accurate.
