# siyuzhong.com

Paintings by Siyu Zhong. A static site: no build step, no framework.

- `index.html` the home page
- `work.html#slug` one painting, with its text
- `writing.html` Written Fragments and notes on the paintings
- `assets/works.js` the list of paintings. Titles, years, sizes and texts live here; edit this file and every page updates.
- `assets/site.css` styles, `assets/ink.js` the drifting threads on the opening screen
- `img/` each painting at 900 px and 2000 px, plus the paper grain, favicon and link preview

Deployed by Vercel from the `main` branch.
